## 🎬 Overview

**XO Arena** is a modern web-based Tic Tac Toe experience designed for **2 local players on the same device**.

The game is fully responsive and works smoothly across:
- 💻 Desktop
- 📱 Mobile
- 📲 Tablets

It is not just a single XO board…  
It is a **collection of interactive XO experiences wrapped in a web platform style**.

---

## 🧠 Core Idea

A simple classic game reimagined into a **modern web experience** with:

- Smooth UI
- Responsive layout
- Theme switching (Dark / Light)
- Instant gameplay with no setup

---

## 🎮 Game Flow

`Open Website → Choose Mode → Play 2 Players → Instant Result → Restart`

---

## ⚔️ Features

- ❌⭕ Classic XO gameplay
- 👥 Local 2-player mode (same device)
- 📱 Fully responsive (Mobile / Desktop / Tablet)
- 🌙 Dark / ☀️ Light theme toggle
- ⚡ Instant restart & fast gameplay loop
- 🎨 Clean modern UI design
- 💻 No installation required (runs in browser)

---

## 🌙 Theme System

The game includes a **dynamic theme switcher**:

- Light Mode ☀️ (clean & bright UI)
- Dark Mode 🌙 (gaming/night vibe UI)

Themes persist smoothly across interactions.

---

## 📱 Responsive Design

This project is built with a **mobile-first approach**, meaning:

- Touch-friendly buttons
- Adaptive board sizing
- Perfect layout scaling on all screens
- No horizontal scrolling issues

---

## 🧩 Tech Stack

- HTML5
- CSS3 (Flexbox + Responsive Design)
- Vanilla JavaScript

## 🎯 What Makes It Different

- Cross-device usability

- Smooth interaction flow
